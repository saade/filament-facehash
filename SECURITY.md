# Security Policy

## Supported Versions

The latest released version of `saade/filament-facehash` receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately rather than
opening a public issue.

- Use GitHub's [private vulnerability reporting](https://github.com/saade/filament-facehash/security/advisories/new), or
- Email **saade@saade.dev** with the details.

Please include:

- A description of the vulnerability and its impact
- Steps to reproduce (proof of concept if possible)
- Affected version(s)

You can expect an initial response within 72 hours. Once the issue is confirmed,
a fix will be released as soon as possible and you will be credited in the advisory
unless you prefer to remain anonymous.
